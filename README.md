# Phone-
The open-source repo for docs.github.com

## Projects

This repository contains documentation and resources for the following projects:

### 1. [Open Source Phone Upgrade](./open-source-phone-upgrade/)
Documentation and guides for upgrading mobile devices with open-source firmware and software. Learn how to install custom ROMs, enhance privacy, and extend the life of your devices.

**Key Features:**
- Custom ROM installation guides
- Privacy-focused solutions
- Community-driven support
- Extended device lifecycle

### 2. [Mindset MindWave](./mindset-mindwave/)
Resources and documentation for working with the NeuroSky MindWave brain-computer interface headset. Explore brainwave monitoring, meditation tracking, and BCI application development.

**Key Features:**
- EEG signal reading
- Attention and meditation metrics
- Multi-platform SDK support
- Research and development tools
